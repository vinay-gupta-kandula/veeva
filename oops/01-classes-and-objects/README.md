
# Classes and Objects in Java

## 1. Introduction
Object-Oriented Programming organizes programs
using classes and objects.

## 2. Class
A class is a blueprint that defines properties
and behaviours of objects.

## 3. Object
An object is an instance of a class that has
its own state and behaviour.(It is a real world physical entity)

## 4. Real-World Analogy
A student record can be represented using
a Student class.

Multiple students can be created as objects.

## 5. Practical Application
In a pharmaceutical CRM application,
HealthcareProfessional objects maintain
doctor information and related operations.

## 9. Key Takeaways

- A class defines the structure of objects.
- Objects are created using the new keyword.
- Each object maintains its own instance state.
- Methods define the behaviour of objects.
